# 🛒 AI Chatbot for E-Commerce Website
A modern and responsive **E-Commerce Website** built using **HTML5, CSS3, JavaScript and Bootstrap**. It demonstrates frontend development skills, interactive UI design, and client-side data persistence using Local Storage enhanced with an **AI-powered shopping assistant chatbot**.

## 🚀 Features
* Responsive homepage design
* Product listing and showcase section
* Product detail pages
* Shopping cart functionality
* Category-based product navigation
* Mobile-friendly interface
* Interactive user experience
* Persistent cart data using Local Storage
* AI-powered shopping assistant chatbot
* Modern and attractive UI design

## 🤖 AI Chatbot Integration
The website includes a floating AI shopping assistant, powered by the **Google Gemini API**, that helps users with product-related queries in natural language.

### How it works
* Injected as a self-contained widget a floating chat button that opens a chat panel on any page
* Automatically fetches the live product catalog and feeds it to Gemini as context, so responses are grounded in real store data
* Answers are restricted to the actual product catalog no invented products, prices, or details
* Chat history is maintained per session for natural, contextual follow-up questions
* Bot responses are rendered with basic Markdown formatting (bold/italic) for readability
* Automatic retry with backoff for transient API overload (503) errors, keeping the chat resilient

## 💾 Local Storage Integration
The application uses the browser's **Local Storage API** to store and manage shopping cart data on the client side.
